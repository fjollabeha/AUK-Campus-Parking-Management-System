# Contributing

## Team Contributions

The project was a collaborative effort, with Marigona, Enis, Anese, and Fjolla sharing responsibilities and contributing equally to the final outcome. The team collaborated on planning, system design, and documentation, working together to ensure consistency and quality throughout the project.

## Documentation

The project's documentation and deliverables are organized in the `docs/` directory.

- **Deliverables:** The Part 1 report and presentation outline are located in `docs/Deliverables/`.
- **Project Documentation:** The project description, scope, design risks, and proposed design patterns are located in `docs/Project_Documentation/`.
- **UML Class Diagram:** The class diagram and its supporting files are located in `docs/UML/Class_Diagram/`.
- **UML Sequence Diagrams:** The diagrams for reserving a parking space, cancelling a reservation, and managing parking availability are located in `docs/UML/Sequence_Diagrams/`.

## Project Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/fjollabeha/AUK-Campus-Parking-Management-System.git
   ```

2. Navigate to the project directory:

   ```bash
   cd AUK-Campus-Parking-Management-System
   ```

3. Open the project in VS Code:

   ```bash
   code .
   ```

4. Review the project documentation in the `docs/` directory, including the Part 1 report, project description, design risks, and UML diagrams.

**Note:** Project Part 1 focuses on system design and documentation. Application implementation will be developed in a later phase.
